# Track: v1.7.0 Enhancements

This track focuses on a series of user experience improvements and new features to bridge the gap between a terminal and an IDE.

## Objectives
- [x] Implement Terminal Persistence (Serialization)
- [x] Add Actionable Project Scripts Panel
- [x] Integrate Git Status Badges in Sidebar
- [x] Support Split Panes (Horizontal/Vertical)
- [x] Expand Smart Detection for Go, Rust, and Docker
- [x] Polished Terminal Search UI
