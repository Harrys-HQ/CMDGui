# Track: v2.0.0 UI/UX Master Overhaul

This track focuses on transforming CMDGui from a functional terminal manager into a premium, IDE-like workspace with a modern layout, enhanced navigation, and improved visual feedback.

## Status: Planning
**Priority:** High
**Owner:** Gemini CLI

## Document Links
- [Implementation Plan](./plan.md)
- [Technical Specification](./spec.md)

## Goals
1. Implement a modern Activity Bar & Top Tab Bar for better navigation.
2. Add a Welcome Dashboard for improved first-run and empty-state experience.
3. Enhance spatial awareness with Breadcrumbs and active pane highlighting.
4. Modernize feedback with a Toast Notification system.
5. Expand customizability with a Global Theme Switcher.
